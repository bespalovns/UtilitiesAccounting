# Учёт услуг ЖКХ

Учебное приложение на платформе «1С:Предприятие 8.3» для учёта коммунальных услуг, расчёта начислений и контроля оплаты.

Приложение поддерживает запуск на компьютере и в мобильной платформе 1С на Android. После загрузки на телефон работает автономно, без постоянного подключения к компьютеру и интернету.

## Возможности

- Ведение справочника квартир: наименование, адрес, лицевой счёт.
- Ведение справочника услуг: единица измерения, тариф, признак расчёта по счётчику.
- Создание начислений по квартире, услуге и месяцу.
- Расчёт расхода по предыдущему и текущему показаниям.
- Расчёт услуг по введённому количеству.
- Учёт полной и частичной оплаты.
- Расчёт оставшейся суммы к оплате.
- Проверка обязательных полей и корректности введённых значений.

## Запуск на компьютере

Для воспроизведения среды разработки рекомендуется использовать **1С:Предприятие 8.3.27.1508**. Возможность запуска на другой версии зависит от её совместимости с конфигурацией.

### Восстановление из выгрузки базы

1. Скачайте `UtilitiesAccounting.dt` из раздела Releases.
2. Запустите 1С:Предприятие.
3. Нажмите «Добавить».
4. Выберите создание новой информационной базы без конфигурации.
5. Укажите название и отдельную папку для базы.
6. Откройте созданную базу в режиме «Конфигуратор».
7. Выберите **Администрирование → Загрузить информационную базу**.
8. Укажите скачанный файл `UtilitiesAccounting.dt`.
9. Подтвердите загрузку и при необходимости перезапуск Конфигуратора.
10. Запустите базу в режиме «1С:Предприятие».

**Загружайте `.dt` в новую пустую базу: восстановление заменяет содержимое выбранной информационной базы.**

### Загрузка из исходников

1. Скачайте и распакуйте репозиторий.
2. Создайте новую пустую информационную базу.
3. Откройте её в Конфигураторе.
4. Выполните **Конфигурация → Открыть конфигурацию**.
5. Выберите **Конфигурация → Загрузить конфигурацию из файлов**.
6. Укажите папку `src`.
7. Выполните **Конфигурация → Обновить конфигурацию базы данных** или нажмите F7.
8. Подтвердите изменения.
9. Запустите режим «1С:Предприятие».

Исходники содержат структуру и код приложения. Записи справочников и документы при загрузке из `src` не переносятся.

## Запуск на Android

Приложение запускается внутри **мобильной платформы разработчика 1С**. Отдельный APK приложения «Учёт услуг ЖКХ» в этом репозитории не распространяется.

Потребуются:

- Android-устройство с совместимой мобильной платформой 1С;
- мобильная платформа, поддерживающая режим совместимости конфигурации **8.3.27**;
- компьютер с Python 3 для первоначальной загрузки;
- подключение телефона и компьютера к одной локальной сети.

### Первоначальная загрузка

1. Установите на телефон мобильную платформу разработчика 1С для архитектуры устройства.
2. Скачайте и распакуйте репозиторий на компьютере.
3. Убедитесь, что в папке `mobile` находятся оба файла:
   - `1cema.xml`;
   - `1Cv8.1CM`.
4. Откройте PowerShell в корневой папке распакованного проекта.
5. Запустите сервер:

   ```powershell
   py -m http.server 8000 --bind 0.0.0.0 --directory mobile
   ```

   Если команда `py` недоступна, используйте `python`.

6. Оставьте окно сервера открытым.
7. Выполните `ipconfig` в другом окне PowerShell и найдите IPv4-адрес компьютера в локальной сети.
8. Подключите телефон к той же сети. При необходимости разрешите входящие подключения к TCP-порту 8000 в брандмауэре Windows для частной сети.
9. Откройте в браузере телефона:

   ```text
   http://IP_КОМПЬЮТЕРА:8000/1cema.xml
   ```

   Вместо `IP_КОМПЬЮТЕРА` подставьте фактический адрес, например `192.168.3.2`. Используйте **HTTP**, а не HTTPS.

10. Если XML открывается, запустите на телефоне «1С:Предприятие».
11. Нажмите «Добавить» или «+».
12. Введите тот же адрес и нажмите «Загрузить».
13. Подтвердите создание приложения.
14. Откройте «Учёт услуг ЖКХ» в списке приложений.

Для ручного запуска отладку и перезапуск из Конфигуратора включать не требуется.

После успешной загрузки Python-сервер можно остановить сочетанием **Ctrl+C**. Приложение продолжит работать на телефоне автономно.
