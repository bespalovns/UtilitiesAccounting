1С:Предприятие 8.3, учебная версия (8.3.27.1508)

Установить платформу 1С:Предприятие, совместимую с версией проекта.  

Скачать UtilitiesAccounting.dt из раздела Releases.  

Создать новую пустую информационную базу.  

Открыть её в Конфигураторе.  

Выбрать «Администрирование - Загрузить информационную базу» и указать скачанный .dt.  

После завершения загрузки запустить базу в режиме «1С:Предприятие».
